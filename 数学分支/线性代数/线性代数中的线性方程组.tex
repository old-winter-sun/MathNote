	\section{线性方程组}
	线性方程：形如$a_1x_1+a_2x_2+\cdots a_nx_n$的方程
	
	$x_n$变量$a_n$系数$b$常数$n$下标
	
	线性方程组：由数个线性方程所组成例：
	$\begin{array}{ll}
		2x_1 - x_2 + 1.5x_3 &= 8\\
		 x_1 -         4x_3 &= -7
	\end{array}$
	
	方程组的解：
	\begin{itemize}
		\item 相容：一个或无穷个解
		\item 不相容：无解
	\end{itemize}
	\begin{itemize}
	\item 解：一组数代入方程组两侧相等
	\item 解集：所以可能的解
	\item 等价的：相同的解集
	\end{itemize}

	矩阵记号：
	表示一个线性方程组的主要信息的紧凑矩阵阵列，称为矩阵
	
	矩阵维数：
	矩阵包含的行数列数。$m\times n$矩阵是一$m$行$n$列矩形矩阵
	
	解线性方程组：
	用等价方程代替
	
	初等行变换：
	\begin{itemize}
		\item 倍加变换
		\item 对换变换
		\item 倍乘变换
	\end{itemize}
